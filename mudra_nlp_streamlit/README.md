# Bharatanatyam Mudra NLP (Streamlit UI)

## Description
This project predicts Bharatanatyam mudras from text descriptions using NLP.

## Run Instructions

1. Install dependencies:
pip install -r requirements.txt

2. Run the app:
streamlit run app.py

## Features
- Text input
- Instant prediction
- Simple UI

## Example
Input: fingers straight and joined  
Output: Pataka
